# Dataset

This project uses the **Employee Attrition in the AI & Hybrid-Work Era** dataset.

## Data Source

The dataset is available on Kaggle:

[Employee Attrition in the AI & Hybrid-Work Era](https://www.kaggle.com/datasets/sergionefedov/employee-attrition-in-the-ai-and-hybrid-work-era)

## Data Description

The dataset contains employee-related information used to analyze and predict employee attrition in the context of AI adoption and hybrid work.

The data includes features related to:

- Demographic information
- Job level and tenure
- Salary and compensation
- Work arrangement and remote work
- Working hours and workload
- Burnout and engagement
- Manager relationship
- Career growth
- Employee attrition

## Target Variable

The target variable is:

- `attrition`
  - `0` = No Attrition
  - `1` = Attrition
